## 6. Where the latency comes from

| Stage | Trigger | Delay contributed |
|---|---|---|
| Capture → `received` | user action / webhook | ~instant |
| `received` → transcription start | **cron `*/5 * * * *`** (`vercel.json:17`) | **0–5 min** |
| Transcription | AssemblyAI, 2s poll, 180s cap (`transcription.ts:65-66`) | seconds–3 min |
| `transcribed` → extraction | **same sweep run** — Stage 2 runs after Stage 1 in the same invocation (`pipeline.ts:99`) | usually 0; **+5 min** if the source was queued past `limit = 10` or the function hit `maxDuration = 300` |
| Extraction LLM | one DeepSeek call, ≤16 384 output tokens | seconds–tens of seconds |
| `proposed` → open proposal in queue | immediate | 0 |
| **Proposal → fact** | **human clicks Confirm** | **unbounded — this is the dominant delay** |
| Fact → lexical searchable | Atlas Search `facts_search` async index | seconds (mongot replication) |
| Fact → semantic searchable | Atlas `autoEmbed` on `facts_vector` — Voyage `voyage-4-large`, 2048 dims, scalar quantization (`retrieval.ts:28-44`); embedding happens **server-side at index time**, none in-process | seconds; index build is async (`setup-indexes.ts:99`) |
| Consolidation / contradiction proposals | **cron `0 3 * * *`** | up to 24h |

Other timing constants:
- Crashed-worker reclaim: `DEFAULT_STALE_AFTER_MS = 10 * 60_000` (`pipeline.ts:34`) — a source stuck in `transcribing`/`extracting` waits ≥10 min before being re-swept.
- Failure retries: `maxAttempts = 3` both stages → a flaky source can burn **3 × 5 min = 15 min** before `failed`.
- Presigned audio GET TTL 1h (`knowledge-pipeline/route.ts:20`); upload token TTL 10 min (`upload/route.ts:15`).
- Throughput ceiling: **10 sources per stage per 5 min ≈ 120 transcriptions + 120 extractions per hour, global across all tenants** (`pipeline.ts:14`), sequential.
- UI polling: `SourceList` refreshes every **15s** while any source is in an active status (`source-list.tsx:21-50`).
- Mongo client: `maxPoolSize: 5`, `serverSelectionTimeoutMS: 10_000` (`client.ts:26-35`).

**Index setup is manual and one-time**: `packages/knowledge/scripts/setup-indexes.ts` — `ensureIndexes` + 4 search indexes (`facts_search`, `facts_vector`, `organizations_search`, `people_search`). Note `:20-23`: the vector index pushes past the M0 3-index ceiling and `autoEmbed` requires Flex/M10+, so on an M0 cluster the semantic arm of `$rankFusion` simply does not exist.</result>
