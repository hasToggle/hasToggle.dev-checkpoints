# MongoDB Atlas capability check — verified 2026-07-31

## 1. $rankFusion / $scoreFusion / "$rank"

**Findings:**
- **$rankFusion: GA.** Shipped GA in server 8.1 (released 2025-06-30); usable on 8.0.x only by opening a support case (feature-flag enablement). Docs: "$rankFusion is only available for deployments that use MongoDB 8.0 and later. You must open a support case to use $rankFusion on 8.0.X versions." $vectorSearch inside input pipelines requires 8.1+. Must be first stage; sub-pipelines limited to $search/$vectorSearch/$match/$sort/$geoNear; no views-in-definition, no time series, no pagination, sub-pipelines run serially.
  - https://www.mongodb.com/docs/manual/reference/operator/aggregation/rankfusion/ (current 8.3 manual)
  - https://www.mongodb.com/company/blog/product-release-announcements/boost-search-relevance-mongodb-atlas-native-hybrid-search (posted 2025-06-25, updated 2026-06-30: "Hybrid search is generally available, including $rankFusion for clusters on 8.0+ and $scoreFusion on clusters on 8.2+")
- **$scoreFusion: GA.** Public preview in 8.2 (2025-09-30), GA in 8.3 (2026-05-31). Current docs instruct: "To use $scoreFusion, your cluster must run MongoDB v8.3 or later."
  - https://www.mongodb.com/products/updates/public-preview-mongodb-native-hybrid-search-with-scorefusion/ ; https://www.mongodb.com/docs/vector-search/hybrid-search/hybrid-search/ ; https://www.mongodb.com/docs/manual/reference/operator/aggregation/scorefusion/
- **Tiers:** these are server stages, no Search Nodes dependency. But M0/Flex clusters are pinned to 8.0 (see Q5), and 8.0.x needs a support case for $rankFusion — so on M0/Flex treat $rankFusion as **effectively unavailable** (no doc says Atlas enabled the flag fleet-wide there — UNCONFIRMED either way). On M10+ it requires choosing "Latest Version With Auto Upgrades" (8.3) or a support case on 8.0.
- **No new stage literally called `$rank` exists.** `$rank` remains the window operator inside $setWindowFields (since 5.0). What the user heard is almost certainly **$rankFusion** (hybrid-search GA marketing, June 2025/2026) — or possibly the brand-new **$rerank** (2026-06-30, see Q4). Related new scoring stage: **$score** (normalize/compute score metadata, in 8.3 manual; arrived with the 8.2/8.3 hybrid-scoring work): https://www.mongodb.com/docs/manual/reference/operator/aggregation/score

**Impact on our design:** None negative — our BM25-only design doesn't use them; if we ever add hybrid search we need a dedicated M10+ on "Latest Version With Auto Upgrades" (8.3), not Flex/M0.
